# 道具箱のレビューを、どう書くか

## 0. まず、読み手がどこに立っているか

商品レビューを読む人は、3つの状態のどれかで来る。
**どの状態に向けて書くかを決めないと、記事は散る。**

| 状態 | 検索する言葉 | 必要なもの |
|---|---|---|
| ① まだ買うと決めていない | 「犬 カート 必要か」 | **買わなくていい条件**。ここで信用が決まる |
| ② どれにするか決まっていない | 「ペットカート 比較」 | 選び分けの軸 |
| ③ 決めたが、踏ん切りがつかない | 「◯◯ 後悔」「◯◯ デメリット」 | **最後の不安をほどくこと** |

**いちばん買うのは③。**「後悔」「デメリット」で調べる人は、買う寸前にいる。
**そして、その人を満足させられるのは、欠点を書いた記事だけ。**

だから「合わなかったこと」の章は、良心の問題であると同時に、
**いちばん売れる章**でもある。ここは一致する。

## 1. 手を止めているのは「買わない理由」

人は「欲しい理由」で買うのではなく、**「買わない理由」が消えたときに買う。**
犬用品で手を止めるのは、だいたいこの5つ。

| | |
|---|---|
| **高い** | 年あたり・1日あたりに割ると見え方が変わる |
| **置き場所** | 寸法を生活に翻訳する。「幅54cm」ではなく「玄関に置けるか」 |
| **うちの子が使ってくれないかもしれない** | **← いちばん強い。犬用品だけの壁** |
| 失敗したときの損 | 返品・交換・中古で売れるか |
| タイミング | まだ早い / もう遅い |

**3つめが決定的。**人が椅子を買うときは、座る前提で考えられる。
**犬は拒否する。**カートに乗らない、ベッドで寝ない、歯ブラシを噛む。

だから **「うちの子に受け入れてもらう手順」は、全部の記事に要る。**
これは親切ではなく、**買わない理由をひとつ消す作業**。

## 2. 「どこかで簡単に見られるもの」を1文字も書かない

読み応えが無くなる理由はひとつしかない。
**公式サイトと Amazon のレビューを10分読めば分かることを、並べ直しているだけ**だから。

超える方法は4つ。**どの記事も、最低3つを含める。**

| | 書けるのは誰か |
|---|---|
| **① 決め方** — 買う / 買わないの判断基準。「あなたの場合はこう」 | 使い分けを知っている人 |
| **② 使ってみないと分からないこと** — 畳んで車に入るか、階段で持てるか、雨の日は | **使った人だけ** |
| **③ 合わなかったこと** — 買わないほうがいい人を、はっきり書く | **使った人だけ** |
| **④ 時間が経ってから分かること** — 1年後、3年後。消耗、手入れ、買い替え | **使い続けた人だけ** |

②③④は**一次体験がないと書けない**。ここがこのサイトの資産（チワワと20年・4匹）で、
競合が絶対に真似できない部分。**一般論で埋めた記事に価値はない。**

**タイトルには年数か頭数を入れる。**「10年使いました」「4匹で試しました」。
これだけで、他の記事と並んだときに選ばれる理由になる。

## 3. 商品の型は4つ。型ごとに、書くことが違う

**8万円のカートと1,500円の歯ブラシに、同じ章立ては要らない。**
迷ったら、この4つのどれかに当てる。

---

### 型A — 長く使う道具

カート / サークル / ベッド / 階段・スロープ / キャリー / 給水器
**2万円以上。何年も使う。**

**買わせるのは「長さ」の話。**高いのではなく、長い。

| 章 | 中身 |
|---|---|
| なぜこの値段なのか | **構造で説明する。**公式は機能を書くが、値段の理由は書かない |
| 年あたり・1日あたり | 8万円 ÷ 10年 = 年8,000円 = 月670円。**安いものを3年で買い替える場合と比べる** |
| サイズ選び | **公式が言わない「どの数字を見るべきか」。**耐荷重ではなく体高、など |
| 置き場所 | 畳んだ寸法を、玄関・廊下・車に翻訳する。**「買う前に measure してください」** |
| 何年目に、どこが傷んだか | **④。この章があるレビューはほぼ無い** |
| 手放すとき | 中古で売れるか。実質の負担額が変わる |
| 受け入れてもらう手順 | **元気なうちに慣らす。**必要になってからでは遅い |

**固有の落とし穴**: スペック表をそのまま載せると読まれない。**全部「生活の言葉」に訳す。**

---

### 型B — 毎日の消耗品

フード / おやつ / トイレシート / 水 / サプリ
**続けて買うもの。**

**買わせるのは「続けられるか」。**一度きりの購入ではないので、**やめ方まで書く。**

| 章 | 中身 |
|---|---|
| 1日あたりいくら | **これが本当の価格。**体重別に出す |
| 切り替えの手順 | **急に変えるとお腹を壊す。**何日かけて、どの割合で |
| 食べなかったときの戻し方 | **買わない理由を消す最大の章。**「合わなかったら戻せる」と分かると買える |
| 保存 | 開けてから何日。冷蔵か常温か。虫・酸化 |
| 何か月続けて、どうだったか | **④** |
| うちの子には合わなかった点 | 便の状態、食いつきの変化。**事実だけ** |

**固有の落とし穴**: **効能を書かない。**「涙やけが治る」「関節にいい」は書けない。
書けるのは「食べた / 食べなかった」「続いた / 続かなかった」まで。
**景表法の前に、医療の線（`Content.swift` が引いた線）と同じ。**

---

### 型C — 体に着けるもの

ハーネス / 首輪 / 服 / 靴 / マナーベルト
**サイズが合わないと、ただのゴミになる。**

**買わせるのは「失敗しない採寸」。**ここでつまずく人がいちばん多い。

| 章 | 中身 |
|---|---|
| どこを、どう測るか | **写真が要る。**首回り・胴回り・着丈。メジャーの当て方まで |
| 体型の落とし穴 | **犬種で違う。**チワワは気管が弱いので首輪より胴。イタグレは胴が細い |
| サイズ表のどこを信じるか | メーカーごとにずれる。**迷ったらどちらに寄せるか** |
| 嫌がる子の慣らし方 | 家の中で数分から。**着けたままおやつ** |
| 返品・交換のしやすさ | **買わない理由を消す。**サイズ違いを交換できる店で買う、という情報自体が価値 |
| 洗ったあと、どうなったか | 縮み・色落ち・金具のさび。**④** |

**固有の落とし穴**: サイズ表を転記しただけの記事が山ほどある。
**「測ってから買う」という行動を起こさせるところまでが仕事。**

---

### 型D — 続ける道具

歯みがき / ブラシ / 爪切り / 耳ケア / シャンプー
**買っても、続かないと意味がない。**

**買わせるのは「挫折しない設計」。**道具の性能より、**続けられる仕組み**を書く。

| 章 | 中身 |
|---|---|
| 1回、何分かかるか | **正直に。**「3分」と書いて5分かかると、次から読まれない |
| どこで挫折するか | **いちばん読まれる章。**嫌がる、暴れる、時間がない、忘れる |
| 段階の踏み方 | いきなり全部やらない。触る → 口を開ける → 前歯だけ、のような順 |
| 続いた期間 | **④。「3年続いています」「半年で挫折しました」どちらも価値がある** |
| 獣医に任せる線 | **ここは必ず書く。**自分でやってはいけないこと（爪の深爪、耳の奥） |
| 合わなかった道具 | 前に使ってやめたものがあれば、なぜやめたか |

**固有の落とし穴**: 「毎日やりましょう」で終わる記事は、誰も動かない。
**やらない日があっていい、という前提で書く**（アプリの方針と同じ）。

## 4. どの型でも、この順番

```
1.  この記事を読まなくていい人      ← 最初に置く
2.  向く人 / 向かない人             ← 結論を先に
3.  迷っている本当の理由はどれか     ← 値段？ 場所？ うちの子が使うか？
4.  〔型ごとの中核〕
5.  合わなかったこと (3つ以上)
6.  買う前に測る・確かめること       ← チェックリストの形で
7.  うちの子に受け入れてもらう手順   ← 全型に必須
8.  長く使う / 続けるための手入れ
9.  まとめ (買う条件 / 買わない条件)
10. 購入リンク + 表示
```

### 1番を最初に置く理由

**「この記事を読まなくていい人」を先に書くと、残った人が全部信じる。**

読者を減らす章に見えるが、逆。**買わない人が早く離脱するので、
最後まで読む人の密度が上がる。**そして「売りたいだけの記事ではない」と伝わる。

これは小手先ではない。**実際、要らない人には要らない。**

### 9番は、両方書く

「買う条件」だけ書くと、宣伝になる。**「買わない条件」を同じ重さで書く。**
読み手は、自分がどちらに当てはまるかを**自分で判断したい。**

## 5. 写真

**使い込んだ実物の写真は、どんな文章よりも強い。**
10年使ったカートの傷んだタイヤ。これは競合が絶対に持っていない。

| 型 | 要る写真 |
|---|---|
| A | 置いた状態の大きさ（**メジャーか、見慣れたものと一緒に**）／ 傷んだ箇所 |
| B | 実物の粒／器に入れた1食分 |
| C | **装着した状態**／測っているところ |
| D | 手と並べた大きさ／使っているところ |

**商品公式の画像を転載しない。**自分で撮ったものだけ。
「本当に持っている」ことが、写真1枚で伝わる。

## 6. 長さ

**価格帯で変える。**1,000円の消耗品に4,000字は要らない。

| 価格 | 長さ | 深さ |
|---|---|---|
| 〜3,000円 | 1,200字 | 使い心地と、合わなかった点 |
| 〜2万円 | 2,000字 | ＋ 競合との違い、サイズ選び |
| 2万円〜 | 3,000〜4,000字 | ＋ なぜその値段なのか、長期の使用感、買わない選択 |

## 7. 守ること

- **使っていないものを、使ったように書かない。** ステマ規制 (景表法) 以前に、一度やると全部の記事の信用が消える
- **案件があるものを書くのではない。書いたものに案件があれば繋ぐ。** 順番を逆にした瞬間に、ぜんぶ安っぽくなる
- **数字は出典のあるものだけ。** 価格・耐荷重・寸法は公式ストアから取り、取得日を書く
- **アフィリエイトのリンクを入れたら、同じ画面に必ず表示を出す。** `build_goods.py` が自動で入れる
- **「合わなかった」を必ず書く。** 欠点のないレビューは読まれないし、買われない
- **医療の判断をしない。** 「この商品で治る」は書かない

## 8. 書き方

`_goods/<slug>.md` を書いて `python3 tools/build_goods.py`。記事と同じ記法。

```
cat: カート
date: 2026-09-14
title: ...            ← 年数か頭数を入れる
lead: ...
forwho: こういう人に向く (1文)
notfor: こういう人には向かない (1文)
shops: 楽天|https://... , Amazon|https://...
draft: true          ← 書きかけのあいだ
---
本文
```

`shops` が空なら購入ボタンとステマ表示は出ない。**審査が通るまでは空のままでいい。**

### 一次体験が要る箇所は、埋めずに残す

下書きの段階では、**体験が要る場所に `【要記入：質問】` を置く。**
質問の形にしておくと、あとから埋めるのが早い。

**この印が残っているあいだは `draft: true` にしておくこと。**
