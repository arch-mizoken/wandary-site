「ペット可」と書いてあっても、**中身はまったく違います。**

部屋の写真より先に、**過ごし方のルール**を見てください。

## 確認するのは、この6つ

| | 違いが大きいところ |
|---|---|
| **大きさ・頭数の制限** | 小型犬のみ、2頭まで、など |
| **部屋に入れるか** | 専用ルームのみ／ケージ内のみ |
| **食事のとき** | 同席できるか。できないなら、犬はどこに |
| **留守番** | **部屋に残して出られるか**（不可の宿が多い) |
| **館内の移動** | 抱っこかカート必須、通れない場所 |
| **ワクチンの条件** | 証明が要るか |

**「食事のとき、犬はどこにいるのか」**を聞き忘れがちです。

## 留守番できないことが多い

いちばん多いつまずきです。

**部屋に犬だけを残すのは不可**、という宿がかなりあります。鳴き声と、いたずらのためです。

つまり、**観光の予定が立てられません。**犬と一緒に行ける場所だけになります。

**先に知っておくと、計画が変わります。**

## 持っていくもの

- **いつものフード**（宿の食事は合わないことがあります）
- **いつもの毛布かマット**（においがあると落ち着きます）
- **ケージかキャリー**（条件になっていることも）
- ペットシーツ、**粘着ローラー**
- タオル(**足を拭く用に多め**)
- **薬**

**毛を落とさない努力**は、次に泊まる人のためでもあります。

## 部屋でのこと

- **ベッドやソファに上げるか**は、宿のルールに従う
- **ドアの開閉**に気をつける(**脱走がいちばん多い**)
- 吠えたら、**一度外に出る**
- 爪で床や壁を傷つけないよう、**爪を短くしてから行く**

**知らない部屋では、粗相することがあります。**ペットシーツを広めに敷いておくと安心です。

## 初めてなら、近くに1泊

いきなり遠くへ行くより、**車で1時間の宿に1泊**。

そこで、

- 知らない場所で眠れるか
- **夜鳴きしないか**
- 食べられるか

**分かってから、遠くへ行けばいいです。**

## 帰ってからを見る

旅行は、思っているより疲れます。

食欲、眠り、下痢。**戻るまでに何日かかったか**を残しておくと、次の計画が立てやすくなります。

**家でのんびりしているほうが好きな子も、います。**それも分かっていい情報です。
