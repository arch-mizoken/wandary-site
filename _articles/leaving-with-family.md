ホテルより気楽で、犬にとっても負担が少ない。**実家に預けるのは、いい選択**です。

ただ、**気心が知れているぶん、説明が省かれます。**そこで事故が起きます。

## いちばん多いのは、食べさせすぎ

**「かわいいから、つい」**です。

- 人の食べ物を分ける
- おやつが増える
- ごはんの量が、目分量で増える

**1週間預けて、帰ってきたら太っている。**よくあります。小型犬だと、1週間でも影響が出ます。

そして**人の食べ物には、あげてはいけないものがあります。**ネギ類、チョコレート、ぶどう。**悪気なく渡されます。**

## 薬は、1回ぶんずつ分けておく

**飲み忘れと、二重投与の両方が起きます。**

- **曜日・時間ごとに、小袋に分ける**
- 「飲ませたら、袋を捨てる」と決める
- 飲ませ方を**実際に見せておく**

**袋が残っているかどうかで、飲ませたかが分かります。**口で確認するより確実です。

## 渡す紙を、1枚

言いにくいことも、紙なら書けます。

| | 書くこと |
|---|---|
| **ごはん** | 量と回数。**それ以上あげない**と明記 |
| **おやつ** | 1日何個までか |
| **あげてはいけないもの** | 具体的に。ネギ類、チョコ、ぶどう、骨 |
| **薬** | 時間と量 |
| **散歩** | 長さと、暑い時間を避けること |
| **いつもの回数** | うんち、おしっこ |
| **連絡先** | 自分と、かかりつけ |
| **何が起きたら連絡** | 判断の線 |

**「それ以上あげないでください」は、紙に書いてください。**口で言うと、角が立ちます。

## 家の環境も、確かめておく

実家には、**犬のいない暮らし**があります。

- **段差と階段**（滑る床、急な階段）
- 庭から**出られないか**
- 届くところに**薬や観葉植物**がないか
- **玄関の開閉**(脱走がいちばん多い)
- **同居の動物**がいるか

**一度、犬を連れて下見に行く**のがいちばんです。

## 高齢の家族に頼むとき

無理をさせない範囲を、決めておきます。

- **散歩は、短く1回でいい**と伝える
- 引っ張る子なら、**散歩は無しでも構わない**
- **抱き上げない**で済む環境にする

**転倒は、犬より人のほうが心配です。**「行かなくていい」と先に言っておくと、無理をしません。

## 帰ってからを見る

- **体重**（いちばん分かりやすい）
- うんちの様子
- 食欲

**責めるためではありません。**次に預けるときに、伝え方を変えるためです。
