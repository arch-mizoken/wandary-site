カートは「歩けなくなった犬の道具」と思われがちです。

**もっと早くから使えます。**そして、**早くから慣らしておくほうが楽です。**

## 元気なうちから使える場面

- **夏のアスファルト**が熱い時間の移動
- 動物病院まで（**待合室でも落ち着けます**）
- 人混みを通るとき
- **長い距離を移動して、現地で歩かせる**
- 子犬で、**ワクチンが終わるまで地面に下ろせない時期**

**移動の道具**として使えば、行ける場所が増えます。

## 歩けなくなってからでは、遅い

これが、いちばんお伝えしたいところです。

**初めて乗せるのが、足が弱ってから**だと、

- **慣らす時間がありません**
- 怖がって乗らない
- 選んでいる時間もない

**元気なうちに1台**あると、そのまま使い続けられます。

## 選ぶときに見るところ

| | 見るところ |
|---|---|
| **耐荷重** | 体重＋荷物。**余裕を見る** |
| **折りたたみ** | 車に積めるか。玄関に置けるか |
| **タイヤ** | 大きいほど段差に強い。小さいと小回りがきく |
| **高さ** | **乗せ降ろしの負担**。低いほうが楽 |
| **通気** | 夏は、中が暑くなります |
| **洗えるか** | 中のマットが外せるか |

**乗せ降ろしの高さ**は、使い続けるうちにいちばん効いてきます。抱き上げる人の腰のためでもあります。

## 型の違い

- **バギー型** — 安定している。段差に強い。大きい
- **キャリーバッグ兼用** — 外して持ち運べる。小型犬向け
- **リュック・スリング** — 小型犬の短距離。手が空く

**電車やバスに乗るなら、ケースとして使えるもの**が便利です。

## 慣らし方

ベッドやクレートと同じです。**急がない。**

1. **家に置いて、何もしない**
2. 中にタオルとおやつを置く
3. **動かさずに、乗って降りる**
4. 家の中を、ゆっくり押す
5. **短い距離**、外へ

**最初から長時間乗せない。**降りたがったら降ろします。

## 乗せるときの安全

- **リードを、カートの中で固定する**（飛び出し防止）
- 下り坂で、**手を離さない**
- **夏は、中の温度**に気をつける（保冷剤を直接当てない）
- 段差は、**前輪を持ち上げて**ゆっくり

## 乗っているだけでも、意味があります

歩けなくなっても、**外の空気とにおいは入ります。**

窓の外を見ているのとは、まったく違います。**公園まで行って、そこで少しだけ歩かせる**という使い方もできます。

> 【要記入：うちでカートを使い始めた時期と、選んだ理由。慣らすのにかかった時間】
