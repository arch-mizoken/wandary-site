フードを替えた日を記録する話は、よく聞きます。

**道具も同じです。**そして、**道具のほうが忘れられます。**

## 替えたものが、理由だったこと

実際に起こります。

- **シャンプーを替えた** → かゆみが出た
- **新しいマットにした** → 足を舐めるようになった
- **ハーネスを替えた** → 散歩を嫌がるようになった（擦れていた）
- **食器を替えた** → 食べなくなった
- **ベッドを替えた** → 別の場所で寝るようになった
- **洗剤・柔軟剤を替えた** → 体を掻くようになった

**どれも、替えたことを覚えていないと、たどり着けません。**

## 書くのは、一言

長く書く必要はありません。

- 「ハーネスを替えた」
- 「マットを新しくした」
- 「シャンプーを変えた」

**日付が入っていれば、それで足ります。**

## 記録する価値が高いもの

全部は要りません。**体に触れるもの**です。

| | なぜ |
|---|---|
| **フード・おやつ** | いちばん影響が出る |
| **シャンプー・洗剤・柔軟剤** | 皮膚に出ます |
| **首輪・ハーネス・服** | 擦れ、きつさ |
| **マット・ベッド・床材** | 接触時間が長い |
| **食器** | 食べ方が変わる |
| **薬・サプリ** | 当然 |

**おもちゃと散歩コースも、余裕があれば。**

## 一度に2つ替えない

これが、いちばん実用的なところです。

**同じ週にフードとシャンプーを替えると、かゆみが出たときに原因が絞れません。**

**1つずつ、1〜2週間あけて替える。**急ぐ理由は、たいてりありません。

## 戻せるようにしておく

替えてから合わないと分かったときのために。

- **前のフードを1週間ぶん残しておく**
- 前のシャンプーを捨てない
- 前の首輪・ハーネスを取っておく

**戻す先があると、判断が速くなります。**

## 診察で、そのまま使えます

「最近かゆがっています」と伝えたときに、必ず聞かれます。

**「何か替えましたか」**

**「3週間前にシャンプーを替えました」**と答えられるかどうかで、話の進み方が変わります。

思い出そうとしても、まず無理です。
