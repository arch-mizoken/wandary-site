撫でていたら、ふくらみに気づいた。

**いちばんやってしまうのが、その場で検索することです。**不安だけが増えて、情報は残りません。

## 先にやるのは、記録です

1分で済みます。

1. **場所を言葉にする**（右の脇腹、左の前足のつけ根、あごの下）
2. **大きさを、身近なもので**（小豆くらい、10円玉くらい）
3. **写真を撮る**
4. **日付を残す**

**これだけで、次に見たときに比べられます。**比べられないと、「大きくなった気がする」で止まります。

## 写真の撮り方

- **近づきすぎない。**周りが写っているほうが大きさが伝わります
- 毛をかき分けて、**地肌が見えるように**
- 明るい場所で
- **同じ角度**で。次に撮るときも同じに

## さわって分かることを、そろえる

| | 伝え方 |
|---|---|
| **硬さ** | 硬い／やわらかい／ぶよぶよ |
| **動くか** | 皮膚と一緒に動く／くっついて動かない |
| **熱** | 熱を持っている |
| **痛み** | さわると嫌がる／平気 |
| **色** | 赤い／黒っぽい／いつもの肌色 |
| **数** | 1つ／いくつもある |

**「動くかどうか」は、よく聞かれます。**指で軽くつまんで、皮膚ごと動くか確かめてください。

## 急ぐのは、この場合

- **急に腫れた**（数時間のうちに）
- **顔やまぶたが腫れている**。そのうえ呼吸がおかしい
- 熱を持っていて、**強く痛がる**
- 破れている、膿が出ている
- **急に大きくなってきた**

**顔の腫れと呼吸が一緒なら、様子を見ないでください。**

## 急がない場合でも、日付は残す

ゆっくりしたものでも、**いつ気づいたかが残っていることに意味があります。**

「3か月前からあって、大きさは変わっていません」と「2週間で倍になりました」は、まったく別の情報です。

**そして記憶は当てになりません。**気づいた日を書いておかないと、あとで「いつからだっけ」になります。

## 次に見る日を、決めてしまう

見つけた日に、**2週間後にもう一度見る**と決めておきます。

同じ場所を、同じ角度で撮る。並べる。**それで変化が分かります。**

変わっていなくても、それは**「変わっていない」という情報**です。診察で役に立ちます。
