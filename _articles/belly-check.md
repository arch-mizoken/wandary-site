お腹は、**異変が出やすいのに、ふだん見ない場所**です。

毛に隠れていて、犬も見せたがらないことがあります。だから**順番を決めておく**ほうが続きます。

## 落ち着いているときに、月に一度

タイミングが全部です。

- **寝転がって、くつろいでいるとき**
- ごはんの直後は避ける
- 嫌がったら、その日はやめる

**撫でているうちに、ついでに**がいちばん続きます。健康チェックの時間を作ろうとすると、たいてい続きません。

## 手のひら全体で、ゆっくり

押し込まないでください。**手のひらを平らにして、すべらせる**ようにさわります。

順番を決めておくと、見落としません。

1. 胸のあたりから、おへそのほうへ
2. 左右の脇腹
3. 内股のつけ根
4. 乳腺のライン（**オスにもあります**）

## 見るのは、この5つ

| | いつもと違うとき |
|---|---|
| **張り** | 全体が硬い、膨らんでいる |
| **しこり** | 小さくても、位置を覚えておく |
| **熱** | 一部だけ熱い |
| **痛み** | さわると鳴く、逃げる、噛もうとする |
| **色** | 赤み、ぶつぶつ、黒ずみ |

**しこりを見つけたら、調べるのは後でいいです。**先にやるのは、**大きさと場所を残すこと**です。

## 大きさは、身近なもので

ミリで測れなくて構いません。

**「小豆くらい」「10円玉くらい」**で十分です。写真を撮るときは、**近づきすぎない**こと。周りが写っているほうが大きさが伝わります。

次に見たときに比べられるよう、**日付と場所**を一緒に残します。右の脇腹、左の内股、のように。

## 急ぐのは、この組み合わせ

- お腹が**急に張ってきた**。そのうえ元気がない
- **吐こうとして、何も出ない**
- 歯ぐきが白っぽい、呼吸が速い
- さわると明らかに痛がる

**この組み合わせは、日を置かないほうがいいものです。**とくに大型犬で、食後に起きたときは急いでください。

> 【あれば：うちでお腹にしこりや張りを見つけたときの話。さわる習慣はいつから始めたか】

**月に一度でいいので、順番どおりにさわる。**いつもを知っていることが、全部の前提になります。
