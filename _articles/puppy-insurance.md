子犬を迎えると、**保険の案内がいろいろ来ます。**

**入る・入らないは、どちらでも構いません。**ここでは、決めるときに見る項目だけ書きます。

> **この記事から、保険会社や代理店へのリンクは貼りません。**比較サイトへの誘導もしません。書けるのは「どこを見るか」までです。

## 入るなら、早いほうが選べます

理由は1つです。

**加入後に見つかった病気は、次の更新から対象外になる**のがふつうです。そして年齢が上がると、**入れる商品が減ります。**

だから「様子を見てから」だと、**選択肢が狭くなります。**

迎えてすぐは健康なことが多いので、**選べる幅がいちばん広い時期**です。

## 見る項目は、6つ

| | 見るところ |
|---|---|
| **補償の割合** | 50%か70%か。保険料と見合うか |
| **年間の上限** | 総額の上限。日額・回数の上限もあるか |
| **対象外** | 予防、去勢・避妊、歯科、健康診断は**たいてい対象外** |
| **待機期間** | 入ってから何日は使えないか |
| **更新時** | 年齢で上がる額。**病気が見つかったあとの扱い** |
| **請求のしかた** | 窓口精算か、あとから請求か |

**「窓口精算ができるか」は、使うときの手間がまったく違います。**

## 対象外になりやすいもの

**ここを知らずに入ると、あとで困ります。**

- ワクチン、フィラリア、ノミダニ予防
- **去勢・避妊手術**
- 健康診断
- **歯石取り**
- 先天的なもの、加入前からあったもの

**つまり、子犬の時期にかかるお金の多くは、対象外です。**

## 入らない、という選び方

これも書いておきます。

**保険料と同じ額を、毎月別の口座に置く。**使わなければ貯まります。

- **自由に使えます**（予防や健診にも）
- 年齢で上がりません
- ただし、**早い時期に大きな病気をすると足りません**

**どちらが正解ということはありません。**

## 実額を記録すると、判断できます

いちばん確実な決め方です。

**1年ぶんの通院費を記録する。**それが保険料より多いか少ないかで、次の年の判断ができます。

ただし保険は、**ならしたときの平均ではなく、一度の大きな出費に備えるもの**です。日帰りで数万円、入院や手術で十数万円から。

**月々のやりくりから出せるかどうか**で考えてください。

> 【要記入：うちで保険に入ったかどうか、その判断。入らなかった子がいれば、その備え方】
