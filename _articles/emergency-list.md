夜中に様子がおかしい。**連れていくべきか、朝まで待てるか。**この判断がいちばんつらいところです。

**迷っている時間が、いちばんもったいない。**だから先に決めておきます。

## すぐ連絡する

**このどれかがあるなら、時間に関係なく連絡してください。**

- **呼吸がおかしい** — 口を開けた呼吸が涼しくしても続く、伏せられない、ゼーゼー
- **歯ぐきや舌の色が違う** — 白っぽい、青白い、紫っぽい
- **意識がはっきりしない** — 呼んでも反応が薄い、倒れる、ふらつく
- **けいれんが5分以上続く**、短時間に繰り返す
- **吐こうとして何も出ない**。お腹が張っている
- **おしっこが半日以上出ていない**
- **大量の出血**、止まらない
- **おなかを強く痛がる**、丸まって動かない
- **後ろ足が両方立たない**、足先の感覚が無さそう
- **何か食べた心当たりがある**（中毒、串、ビニール、薬）
- **熱中症が疑われる** — 涼しくしても戻らない
- **目が急に開けられない**、飛び出して見える
- **お産が進まない**

## 朝まで待てることが多い

**ただし、組み合わせによります。**

- 下痢だけ。元気も食欲もある
- 吐いたが1回だけ。そのあとケロッとしている
- 軽く足を引きずる。体重はかけられる
- 目やにが増えた。目は開けられる
- 耳を掻く回数が増えた

**どれも「それだけなら」です。**ぐったりしている、食べない、飲まないが重なったら、上の列に移ります。

## 子犬とシニアは、一段早く

**余力が少ないぶん、進みが早くなります。**

子犬は、食べない・飲まないだけで危ないことがあります。シニアは、ひとつの変化が重なりやすい。

**同じ症状でも、判断の線を一段手前に引いてください。**

## 電話する前に、手元に

聞かれることは、だいたい決まっています。

| | |
|---|---|
| **体重** | いまの体重 |
| **年齢** | と、犬種 |
| **いつから** | 何時ごろからか |
| **何が起きているか** | 見たまま |
| **食べたもの** | 心当たりがあれば、何を・いつ・どれだけ |
| **持病と薬** | 飲んでいるもの |

**1か所にまとまっていると、慌てずに済みます。**

## 先にやっておくこと

**いま、5分でできます。**

1. **かかりつけの電話番号**をスマホに登録
2. **夜間・救急の動物病院**を調べて、登録
3. そこまでの**行き方と、所要時間**を確認
4. **診療時間**と、受付の方法（電話が要るか）

**探しはじめるのが夜中では、遅いです。**
