犬と入れるカフェは増えました。ただ、**行けば楽しめるわけではありません。**

落ち着いて伏せていられない子にとっては、**1時間の我慢**になります。

## 家でできる練習が、ほぼ全部です

カフェで必要なのは、**伏せて待てること**だけです。

- 家で、**マットの上で伏せる**練習
- 時間を少しずつ伸ばす（1分 → 5分 → 15分）
- 人の出入りがあっても、**マットから出ない**

**同じマットを持っていくと、そこが「いつもの場所」になります。**これがいちばん効きます。

## 行く前に決めること

- **短い時間で切り上げる**（最初は30分）
- 行く前に**散歩**を済ませる（疲れていると落ち着きます）
- **トイレを済ませてから**入る
- 混む時間を避ける

**空いている時間に、短く。**成功体験から始めます。

## 持ち物

| | なぜ |
|---|---|
| **マットかブランケット** | 居場所が決まる。椅子やソファを汚さない |
| **水と器** | 店で出ないこともあります |
| **おやつ** | 落ち着いているときに渡す |
| **ペットシーツとビニール** | 粗相のとき |
| **おもちゃ(音の出ないもの)** | ひまつぶし |

## 店ごとのルールを、先に見る

同じ「犬OK」でも、中身が違います。

- **テラスのみ**か、店内も可か
- **床に下ろせる**か、カートや椅子の上のみか
- 大きさの制限
- **ワクチン証明**が要るか
- おむつ・マナーベルトが必要か

**サイトに書いてあることが多いです。**行ってから分かると、気まずくなります。

## ほかの犬がいることを前提に

**自分の犬だけを見ていてください。**

- 近づけない。**相手の飼い主が誘っても、こちらが断っていい**
- リードは短く。テーブルの脚に結ばない（**引っ張ったら倒れます**)
- 吠えたら、**一度外に出る**

**無理をして居続けないこと。**嫌な記憶になると、次が難しくなります。

## 合わない子も、います

これは書いておきたいところです。

**人の多い場所が苦手な子は、います。**それは性格であって、しつけの問題ではありません。

**行かなくても、その子は困りません。**静かな散歩のほうが楽しい子もいます。

> 【あれば：うちでカフェに行ったときの話。うまくいった場所と、合わなかった場所】
