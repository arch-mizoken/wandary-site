子犬を迎えるとき、**かわいさで決めてしまいます。**無理もありません。

ただ、**その場でしか聞けないこと**があります。

## 法律で決まっていること

まず、売る側に義務があることを知っておいてください。

- **対面での説明と、現物の確認**（ネットだけで売買はできません）
- **生後56日(8週)を過ぎていること**
- **マイクロチップが装着され、登録されていること**（2022年6月以降）

**これらが守られていない場合は、その時点で考え直す理由になります。**

## 聞いておくこと

| | なぜ |
|---|---|
| **生年月日** | 月齢で、やることが変わります |
| **ワクチンの接種日と種類** | 次をいつ打つか決まります |
| **駆虫をしたか** | いつ、何を |
| **いま食べているフード** | **銘柄と量。**替えると、お腹を壊します |
| **親犬の様子** | 見せてもらえるか。性格、体格 |
| **きょうだいの頭数** | 社会化の参考に |
| **これまでの健康状態** | 下痢、嘔吐、治療歴 |

**フードは、必ず聞いてください。**迎えてすぐ替えると、ほぼ確実にお腹を壊します。

## 親犬を見せてもらえるか

**これは、かなりの判断材料になります。**

- 成犬になったときの**体格の目安**
- 性格の傾向
- **育てている環境**が見える

**見せられない理由を説明されるなら、それも情報です。**

## 保証について

書面で確認します。

- **先天的な疾患が見つかった場合**の対応
- **生体保証の期間**と、条件
- 健康診断を受ける期限（**条件になっていることがあります**）

**口頭ではなく、書いたものをもらってください。**

## 迎えたあと、すぐやること

| いつ | やること |
|---|---|
| **数日以内** | **動物病院で健康診断**（保証の条件になっていることも） |
| **生後91日を過ぎたら** | 市区町村への**犬の登録** |
| **登録のとき** | 鑑札をもらう。首輪につける |
| **30日以内** | **マイクロチップの飼い主変更**の届け出 |
| 獣医師と相談して | 次のワクチン、フィラリアの開始 |

**マイクロチップの変更届は、忘れやすいところです。**前の所有者のままだと、迷子のときに意味がありません。

## 保護犬という選択もあります

**迎え方は、ひとつではありません。**

保護団体や自治体から迎える道もあります。**成犬なら、性格と体格が分かっている**という利点があります。

別の記事に書いています。

## 聞いたことを、残しておく

**あとから聞けなくなります。**

生年月日、前のフード、ワクチンの日、親犬のこと。**メモして、記録と一緒にしておいてください。**

何年かあとに「子犬のころはどうでしたか」と聞かれることがあります。
