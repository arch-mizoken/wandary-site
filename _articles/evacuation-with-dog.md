災害のとき、**犬を連れて避難できるかどうかは、自治体で違います。**

そして**調べはじめるのが当日では、遅いです。**

## 言葉を、2つ分けて覚える

混同されやすいところです。

- **同行避難** — 一緒に避難所まで**行く**こと。犬は別のスペースで過ごします
- **同伴避難** — 避難所の中で、**一緒に過ごす**こと

**国が推奨しているのは「同行避難」**です。一緒の部屋で過ごせるとは限りません。

**「ペット可」と書いてあっても、どちらなのかを確かめてください。**

## 今日、5分で調べること

お住まいの市区町村のサイトで、「**(市町村名) 避難所 ペット**」と検索します。

- **近くの避難所が、受け入れるか**
- 同行か、同伴か
- **ケージが必要か**（必要なことが多いです）
- 受け入れ条件（**ワクチン、鑑札、マイクロチップ**）

**書いてなければ、電話で聞いてください。**平時なら、すぐ教えてもらえます。

## ケージが、条件になることが多い

ここがいちばん実務的なところです。

**避難所では、ケージに入れることが条件**になるのがふつうです。

**ふだんクレートに慣れていない子は、ここでつまずきます。**災害時に初めて入れられると、鳴き続けます。

**避難のための練習ではなく、ふだんの居場所にしておく。**それが準備になります。

## 持ち出すもの

**人の防災バッグとは別に、犬のぶんを作ります。**

| | |
|---|---|
| **フード** | 最低5日ぶん。**いつものもの** |
| **水** | 犬用に別で |
| **薬** | 飲んでいるもの、数日ぶん |
| **ケージかキャリー** | 折りたためるものがあると楽 |
| **ペットシーツ、ビニール袋** | 多めに |
| **リードの予備** | 1本は必ず予備を |
| **食器** | 折りたためるもの |
| **写真** | **飼い主と一緒に写ったもの**（はぐれたとき) |
| **ワクチンの記録** | 条件になることがあります |

## 迷子のための準備

**はぐれる前提で、準備しておきます。**

- **鑑札と迷子札**をつけておく
- **マイクロチップの登録情報**が、いまの連絡先か確かめる
- **一緒に写った写真**をスマホに（自分の犬だと示せます）

**引っ越したあとに登録を直していない**ことが、よくあります。今日確かめられます。

## 預け先を、決めておく

避難所に入れない場合に備えて。

- 遠方の家族・友人
- **ペットホテル**（災害時に預かるか、聞いておく）
- 車中泊できる場所（**夏は危ない**）

**選択肢が2つあるだけで、当日の判断が速くなります。**
