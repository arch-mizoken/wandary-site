「犬の鼻が乾いていたら、体調が悪い」。よく聞く話です。

**そこまで当てになりません。**寝ているあいだは乾きますし、暖房のそばでも乾きます。

## 乾きは、一日の中で変わります

鼻の湿り気は、こんなことで変わります。

- 寝起き（**寝ているあいだは乾きます**）
- 暖房や、乾燥した部屋にいたあと
- 運動の直後
- 年齢（シニアは乾きやすくなります）

**乾いているだけで、ほかに何もないなら、まず様子を見て構いません。**

## 気にするのは、出ているもの

乾きより、こちらのほうが情報になります。

| | いつもと違うとき |
|---|---|
| **色** | 黄色っぽい、緑っぽい |
| **量** | 垂れるほど出ている |
| **左右** | **片方だけ**から出ている |
| **血** | 混じっている |

**片方だけ、はとくに伝える価値があります。**両方かどちらかで、見る順番が変わります。

## 皮が剥ける・色が抜ける

表面の変化も見ておきます。

- かさぶたのようになる、皮が剥ける
- ひび割れている
- **もともとの黒が、薄くなってきた**
- 鼻を気にして、こすりつける

色が抜けるのは、季節で変わる子もいます。**去年の同じ時期の写真があると、比べられます。**

## 冬は、乾燥そのものが理由のことも

冬に鼻や肉球が硬くなるのは、部屋の乾燥のことがあります。

加湿する、暖房の風が直接当たらないようにする、寝床を窓際から離す。**環境を変えるだけで戻ることがあります。**

同じ時期に、**フケが増える・静電気がひどい・肉球が硬い**が揃っているなら、乾燥のほうを疑ってみてください。

## 急ぐのは、組み合わせたとき

- 鼻水に加えて、**咳・くしゃみが続く**
- **食欲が落ちている**、元気がない
- **呼吸が速い**、口を開けて苦しそう
- 鼻血が出た

**鼻だけを見て判断しないでください。**ほかに何が起きているかで意味が変わります。

> 【あれば：うちで鼻の変化に気づいたときの話。乾きだったのか、出ているものだったのか】
