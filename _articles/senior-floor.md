**フローリングは、犬にとって滑ります。**

若いうちは踏ん張れますが、**踏ん張ること自体が負担**です。そしてシニアになると、踏ん張れなくなります。

## 滑るのは、原因にも結果にもなります

ここが大事なところです。

滑る → 踏ん張る → 足腰に負担 → 力が落ちる → もっと滑る。

**この輪は、床を変えるだけで切れます。**

## まだ元気なうちに変える

**転んでからでは、遅いことがあります。**

- 滑って転ぶと、**それ自体でけがをします**
- 一度怖い思いをすると、**歩かなくなる**ことがあります
- 歩かないと、さらに力が落ちます

**シニアと呼ばれ始める年齢になったら、そこで一度見直してください。**

## 床で、できること

上から順に、効きます。

| | |
|---|---|
| **タイルカーペット** | 汚れたところだけ替えられる。いちばん現実的 |
| **コルクマット** | クッション性がある。爪が引っかかりにくい |
| **滑り止めワックス** | 見た目が変わらない。効果は数か月 |
| **ラグを敷く** | 端がめくれると、かえって危ない |

**生活動線に敷くのが先です。**全面でなくて構いません。

- 寝床からトイレまで
- 寝床から水の器まで
- **玄関まわり**
- よく曲がる角

## 足の裏も、滑る原因

床だけではありません。

- **肉球のあいだの毛**が伸びていると、滑ります
- **爪が伸びている**と、肉球が接地しません

**トリミングのときに「肉球のあいだをお願いします」**と伝えてください。家で切るなら、バリカンのほうが安全です。

## 段差は、無くすか、緩やかにする

- **ソファやベッドに、スロープか階段**をつける
- 玄関の段差に、踏み台
- **行かせたくない段差は、ゲートで塞ぐ**

**飛び降りさせないこと。**着地の衝撃が、いちばん負担になります。

胴の長い子は、とくに気をつけてください。

## 抱き方も、見直す

**脇だけで持ち上げると、背中に負担がかかります。**

**お尻と胸を両方支えて、背中がまっすぐなまま**持ち上げます。家族全員で揃えてください。

## 変えた日を、記録に残す

一言で構いません。「リビングにマットを敷いた」。

**そのあと歩き方がどう変わったか**を並べて見られます。効いたなら、ほかの部屋にも広げる理由になります。

> 【要記入：うちで床と段差をどう変えたか。変えてから、どう変わったか】

**どれも、いつからでもできます。**そして早いほど効きます。
