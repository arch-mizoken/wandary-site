国内線では、**犬は貨物室に乗ります。**（介助犬をのぞく）

客室に連れて入れる航空会社は、国内ではごく限られます。**まず、そこを知っておいてください。**

## 乗せない、という選択がまずある

**この記事でいちばん伝えたいことです。**

- **短頭種**（鼻のつぶれた犬種）は、**預かりを断られる**ことがあります。呼吸の負担が大きいためです
- **夏と冬は、受付を制限**する会社があります
- シニア、持病のある子、心臓や呼吸器に不安のある子
- **極端に怖がりな子**

**預けるのをやめて、車にする、留守番にする、預ける。**それも立派な選択です。

## 航空会社ごとに、条件が違う

必ず、乗る会社のサイトで確認してください。

| | 確認すること |
|---|---|
| **ケージ** | 大きさ、素材、鍵の形 |
| **料金** | 区間ごと |
| **予約** | 事前申し込みが必要なことが多い |
| **同意書** | 当日サインします |
| **季節の制限** | 夏季・冬季の取り扱い |
| **犬種の制限** | 短頭種など |

**当日に空港で「乗せられません」と言われる**ことがあります。先に電話で確認してください。

## ケージに慣れていることが前提

貨物室では、**数時間ひとりでケージの中**です。

ふだん入れない子が、いきなり入れられて、知らない音と振動の中に置かれる。**負担が大きすぎます。**

**最低でも数週間は、家で慣らしてから。**それができないなら、乗せないほうがいいと思います。

## 当日の段取り

- **ごはんは、数時間前までに**
- 水は、**出発前に少し**
- **トイレを済ませる**
- 空港では、**ぎりぎりまで一緒にいる**
- **早めに着く**（手続きに時間がかかります）

**ケージには、においのついたタオル**を入れておくと落ち着きます。

## 到着してからを、見る

降りてすぐに見るところです。

- 呼吸が落ち着いているか
- **水を飲むか**
- 震えていないか
- ぐったりしていないか

**異変があれば、空港で言ってください。**そのまま移動せず、近くの動物病院へ。

## 代わりの手を、先に考える

飛行機以外に、方法があることも多いです。

- **車で行く**（時間はかかりますが、休憩を挟めます）
- **ペットタクシー**や陸送サービス
- **現地でレンタカー**にして、犬は預ける
- そもそも**連れていかない**

**どれが犬にとって楽か**で決めていいと思います。
