「鼻が熱いから、熱があるかも」。**これはあまり当てになりません。**

鼻も耳も、気温や寝起きで変わります。

## 測るなら、おしりで

正確に知りたいなら、方法は一つです。

**ペット用の体温計**を、おしりから。先端にワセリンを塗って、**無理に奥まで入れない。**嫌がるなら、やめてください。

犬の平熱は、人より高めです。**その子の平熱を、元気なうちに1〜2回測っておく**と、比べられます。

**耳で測るタイプ**もありますが、入れ方で数字が変わりやすいです。

## 測れないときに、見るところ

嫌がる子、持っていない人のほうが多いと思います。そのときは、ほかを見ます。

| | いつもと違うとき |
|---|---|
| **耳のつけ根・内股** | いつもより明らかに熱い（**左右とも**） |
| **元気** | 寝ている時間が長い、呼んでも来ない |
| **食欲** | 食べない、水だけ飲む |
| **呼吸** | 速い、浅い |
| **震え** | 寒いわけでもないのに震える |
| **鼻水・くしゃみ・咳** | 一緒に出ているか |

**体温そのものより、組み合わせのほうが情報になります。**

## 「熱っぽい」だけでは伝わりません

診察で役に立つのは、こちらです。

- **いつから**、様子が違うか
- **食べているか、飲んでいるか**
- 元気の落ち方（**寝ているだけ／呼んでも来ない**）
- ほかの症状（咳、下痢、吐く、震え）
- **最近あったこと**（ワクチン、手術、散歩先、暑い場所）

**ワクチンのあと**に出ることがあります。何日前に打ったかは伝えてください。

## 暑さによるものは、別です

**室温が高い場所にいたあと**や、**夏の散歩のあと**にぐったりしているのは、熱が出ているのとは別の話です。

**涼しい場所に移して、風を当て、常温の水を。**氷水で急に冷やさないでください。

**涼しくしても戻らないなら、様子を見る場面ではありません。**

## 急ぐのは、この組み合わせ

- ぐったりして**動かない、反応が薄い**
- **震えが止まらない**
- **食べない・飲まない**が続いている
- **呼吸が速い**、歯ぐきの色が違う
- 子犬やシニアで、元気がない

**とくに子犬とシニアは、余力が少ないぶん進みが早くなります。**
