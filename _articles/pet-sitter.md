環境が変わるのが苦手な子には、**家に来てもらうほうが向いています。**

ただし、**家に人を入れる**ことになります。選び方が変わります。

## 資格と、保険

まず確認するところです。

- **動物取扱業の登録**があるか（事業所に標識があります）
- **損害賠償保険**に入っているか
- 鍵の管理方法
- 会社なら、**担当者が毎回同じか**

**登録番号は、名刺やサイトに書いてあります。**無い場合は、理由を聞いてください。

## 事前の打ち合わせがあるか

**これがいちばんの判断材料**だと思います。

本番の前に一度来てもらって、

- 犬と顔を合わせる
- 家の中の動線を見てもらう
- ごはんや薬の場所を確認
- **犬が、その人を受け入れるか**を見る

**事前訪問が無料か有料かは、会社によります。**無いところは、避けていいと思います。

## 決めておくこと

| | |
|---|---|
| **1回の滞在時間** | 30分か、1時間か |
| **1日に何回** | 留守の長さで変わります |
| **散歩に出すか** | 外に出すかどうか |
| **報告の方法** | 写真つきの連絡があるか |
| **鍵の受け渡し** | 当日か、事前か |

**報告があるかどうかは、留守中の安心がまるで違います。**

## 家の側の準備

- **入ってほしくない部屋**は、閉めておく
- 貴重品はしまう
- **ごはんと薬を、1回ぶんずつ分けておく**
- 掃除道具とごみ袋の場所を伝える
- **エアコンの設定**を決めておく

## 渡す紙を、1枚

ホテルと同じです。口で説明すると半分は伝わりません。

- ごはんの量と回数
- **薬の時間**
- 苦手なもの、やってはいけないこと
- **いつもの回数**(うんち、おしっこ)
- **かかりつけの連絡先**と、自分の連絡先
- **何が起きたら、連絡してほしいか**

**最後のを書いておくと、判断を任せられます。**

## 留守番の長さは、変わりません

シッターが来ても、**ほとんどの時間はひとり**です。

1日2回、30分ずつ来てもらっても、**残りの23時間はひとり**です。

**長い留守番が苦手な子は、ホテルのほうが向いている**こともあります。どちらが合うかは、その子次第です。
